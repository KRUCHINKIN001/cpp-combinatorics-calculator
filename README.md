# Калькулятор комбинаторики (C++)

Консольная программа для вычисления перестановок, размещений и сочетаний. Позволяет выбрать метод через интерактивное меню, запрашивает только необходимые параметры и обрабатывает ошибки ввода и переполнения.

## Методы и формулы

1. **Перестановки:** \(P_n = n!\)
2. **Размещения:** \(A_n^k = \frac{n!}{(n-k)!}\)
3. **Сочетания:** \(C_n^k = \frac{n!}{k!(n-k)!}\)

## Особенности реализации

- **Защита от переполнения:** Перед умножением программа проверяет, не выйдет ли результат за пределы типа `unsigned long long`. Для размещений и сочетаний используются оптимизированные пошаговые вычисления, чтобы избежать лишнего переполнения.
- **Валидация ввода:** Программа не позволяет ввести буквы вместо цифр, а также проверяет, что \(k \le n\).
- **Возврат в меню:** После каждого вычисления программа возвращается в главное меню. Выход осуществляется по нажатию `0`.

## Пример работы

```text
=== КАЛЬКУЛЯТОР КОМБИНАТОРИКИ ===
1. Перестановки
2. Размещения
3. Сочетания
0. Выход
Выберите метод: 3

Введите n: 10
Введите k: 3
Результат: C(10, 3) = 120
